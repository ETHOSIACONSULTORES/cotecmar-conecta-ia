# Backlog recomendado para producción

## Prioridad alta
- SSO/MFA y RBAC.
- Auditoría de acciones.
- Escaneo de malware de adjuntos.
- Object storage.
- Backups y restauración.
- OCR para documentos escaneados.
- Protección contra abuso/rate limiting.
- Observabilidad y alertas.
- Migraciones de DB con Alembic.

## Prioridad media
- Filtros y comparación avanzada por evento/ciudad/sector.
- Exportación XLSX/PDF de informe de evento.
- Notificaciones y workflow de seguimiento.
- Historial de versiones de necesidades.
- Integración con ERP/portal de compras.
- Georreferenciación y mapas.

## IA / Gobierno
- Rubrica de scoring aprobada por Compras.
- Evaluación de sesgo y calidad.
- Dataset de validación.
- Monitoreo de drift/cambios de modelo.
- Registro de modelo, prompt y versión por análisis.
